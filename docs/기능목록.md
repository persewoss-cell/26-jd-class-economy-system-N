## 의도적으로 바꾼 점 (선생님 확인 완료)
1. **빠른 금액**: 같은 버튼을 연속으로 눌러도 매번 더해짐 (기존은 두 번째부터 반응 없음)
2. **🎯 목표**: 진행 중 적금 원금 + 목표일 이전 만기 이자를 실제로 포함 (기존은 오류로 미반영)
3. **👥 계정 정보 표**: 고친 번호/이름/비밀번호를 `💾 변경 저장`으로 실제 저장
4. **적금 이자율 등급**: 화면의 신용등급과 같은 기준(수동 조정 포함)으로 통일
5. 관리자 비밀번호는 코드가 아닌 서버 환경변수(`ADMIN_PIN`)에 저장
6. 잔액 변경을 원자적으로 처리해 동시에 눌러도 금액이 어긋나거나 두 번 지급되지 않음
7. 표: 제목을 누르면 정렬, `⬇ CSV`로 내려받기 (Streamlit 표 기능과 동일)
8. 디자인: 메인 메뉴 앞 동그라미 제거, 선택된 버튼(메뉴·라디오·빠른 금액)은 한 가지 색으로 통일. 통계표 O(초록)/X(빨강)/△(파랑)만 색 구분 유지
9. 💰입금/출금(관리자): 국고 반영 체크칸을 직접 누르지 않았으면 [입금]/[출금]을 누를 때마다 "국고에 반영할까요?" 팝업 (직접 체크했으면 팝업 없이 그대로 반영)
10. **입금/출금 방식**: 금액칸 하나 + 맨 아래 [💰 입금] [💸 출금] 버튼(국세청은 [📥 세입] [📤 세출]). (+)/(-) 전환을 깜빡해 반대로 처리되는 실수 방지. 템플릿을 고르면 그 종류 버튼이 색으로 강조됨
11. **권한 학생의 관리자 탭**: 관리자와 완전히 같은 화면·기능 (문구 차이 제거, 신용 수동 조정 포함)
12. **통계·신용 장부**: 7개씩 페이지 넘김 → 번호·이름 고정 + 옆으로 밀어서 전부 보기
13. 로그기록 "필요할 때만 불러오기" 버튼 등 Streamlit 속도용 장치 제거

## 기존에도 화면에 없던 기능 (옮기지 않음)
- PDF 금리표 파싱, 직업표 엑셀(직업표/월급 명세서 시트) 파싱, 🗓️ 일정 — 원본에 함수만 있고 화면에서 쓰이지 않음
14. **새 디자인**: 민트+라벤더 파스텔 테마, 상단 바·카드형 화면·알약 메뉴, 학생 요약은 카드, Pretendard 글꼴
15. **속도**: 서버를 DB와 같은 서울(icn1)에서 실행, 한 번 연 탭은 바로 표시(뒤에서 최신화), 로그인 직후 탭 데이터 미리 불러오기
16. **입금/출금 화면 2줄 배치**: [템플릿][내역][국고 반영] / [금액][+10…지우기][입금][출금][되돌리기]. 학생 화면엔 되돌리기 없음
17. **엑셀 일괄 추가**: 모든 탭에서 [파일][샘플][현재] / [덮어쓰기][저장] 두 줄로 통일
18. **권한 부여 현황**: "추가 탭"과 "관리자 기능" 칸을 "부여된 권한" 하나로 합침
19. **직업 해제·권한 회수**: 팝업 체크 목록에서 골라 해제/회수 (전체 버튼 없음)
20. **상단 정리**: 로그인 화면은 카드 안에 제목, 학생은 상단 바 없이 총 자산 카드에 이름·비밀번호 변경·로그아웃, 관리자는 제목 가운데 + [계정관리][로그아웃]
21. **개인 입금/출금**: 학생을 체크하지 않으면 빨간 경고만 뜨고 처리되지 않음
22. **되돌리기·회수는 모두 기록 삭제 방식**: 월급 중복 회수·이번달 전체 회수, 개별조회 통장내역 삭제, 입금/출금 되돌리기 모두 "회수/정정/환급/되돌리기" 기록을 새로 만들지 않고 원래 기록(학생 통장 + 국고)을 지워 원래 상태로 복구. 이후 기록의 총액도 맞게 정정
23. **월급 한 달 한 번**: 전체 회수하면 그 달 지급 기록도 지워 다시 지급 가능. 지급일이 지난 뒤 전체 회수한 경우엔 자동지급을 멈추고 "다시 지급할 날" 팝업(그날 자동지급 / 이번 달은 안 함)
24. 적금 중도해지·만기, 경매 반환, 투자 회수, 마트 구입처럼 실제로 일어난 거래는 지금처럼 기록을 남김 (예전에 생긴 회수/되돌리기 기록은 그대로 둠)
25. **점검 후 정리**: 마트 승인 시 잔액이 부족하면 승인 안 됨, 0보다 작은 금액 입력 차단, 계정 엑셀/생성에서 '입출금활성화' 항목 제거
26. **확인 팝업 추가**: 입금 요청 전체승인·전체거절, 경매 마감, 복권 마감 (지우기·마감 같은 버튼은 빨간색, 처리 중엔 두 번 눌리지 않음)
27. **복권**: 3등 당첨금 0·1등 0% 설정 가능, 지급이 시작된 회차는 당첨번호 변경 불가, 지급 도중 오류 후 다시 지급해도 이미 받은 학생은 중복 지급 안 됨
28. **표 정렬(엑셀처럼)**: 모든 표(팝업 포함) 머리글 오른쪽 세모 — 검은 ▼(기본) → 파란 ▼(내림차순) → 빨간 ▲(오름차순) → 다시 기본 순서. 숫자·날짜는 크기/시간 순, 빈 칸은 항상 아래, 통계·신용 장부의 일괄/평균 줄은 제자리
29. **템플릿 순서 ▲▼**: 입출금·국고·통계표·마트 템플릿과 직업의 수정/삭제 드롭다운, 그리고 입금/출금·국고·제출물 추가 칸의 템플릿 선택 드롭다운과 직업 지정의 "부여할 직업 선택"(관리자·권한 학생)에서 각 줄 오른쪽 ▲▼로 순서를 바꾸면 바로 저장(1, 2, 3…으로 다시 매김), 고른 항목과 '순서' 칸도 따라감
30. **통계표 템플릿 엑셀 일괄 추가**: 통계청 탭 맨 아래 [템플릿 내역, 순서], 이미 있는 내역은 건너뜀, 덮어쓰기 가능
31. **여러 명 입금/출금 중 한 명만 삭제(개별조회)**: 그 학생 기록·잔액과 함께 국고에서도 그 학생 몫만 되돌림 (전체 일괄은 국고 금액을 줄이고, 마지막 학생이면 기록 삭제)
32. **통계·신용 장부**: 위아래 스크롤 없이 전체 학생이 한 화면에 모두 표시 (제출물 열이 많으면 좌우로만 밀어서 봄)
33. **투자 주가 변동 기록 ✏️ 수정 / 🗑️ 삭제(관리자)**: 표 맨 오른쪽 버튼. 수정은 팝업에서 변동 사유·실제주가(환산주가 미리보기), 삭제는 확인 팝업. 다음 기록의 등락·그래프가 이어지고, 마지막 기록이면 종목 현재 주가와 진행 중 투자 평가에 반영. 그 주가로 산 아직 회수 안 한 투자는 매입주가도 정정(회수 끝난 투자는 그대로)
34. **주가 그래프 💾 저장 / 🖨️ 인쇄**: 그래프 오른쪽 위 작은 아이콘. 인쇄용으로 새로 그린 꺾은선 그래프(주아 제목, 왼쪽 일정 간격 눈금 숫자, 상승 빨강·하락 파랑·보합 검정 선과 점, 점마다 값, 아래 항목 줄바꿈)를 A4 가로 그림(PNG)으로 저장하거나 A4 가로로 인쇄
35. **로그기록 보강**: 투자 주가·종목, 직업·월급 설정, 계정·권한(부여/회수), 각 탭 템플릿·순서, 마트·신용·복권·경매 설정 변경을 "변경" 기록으로 남김 (예전 '권한 보유 상태' 줄은 실제 부여/회수 기록으로 대체)
